# Text Analyzer

A simple Python application that analyzes user input.

## Features

- Accepts user name and age
- Calculates future age
- Demonstrates basic Python functionality
- Demonstrates Git and GitHub workflow

## Technologies

- Python
- Git
- GitHub

## How to Run

Clone the repository:

git clone https://github.com/marikalsaitarun/text-analyzer.git

Go to the project:

cd text-analyzer

Run the application:

python app.py
